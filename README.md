# 薬学てらこやの宿題

一問一答の演習アプリです。ブラウザで開くだけで使えます。

**→ https://terakoyano-syukudai.github.io/**

収録：微生物免疫学・病態学・衛生・薬理学・解剖学・薬物動態学・生化学・分子生物学の7科目、12157問。

---

## 使う人へ

- スマホでもパソコンでも動きます。アプリのインストールは不要です。
- **ホーム画面に追加して使ってください。** 1回目だけ読み込み（約1.7MB）が走り、
  **2回目からは通信を使いません**。電波のない場所でも解けます。
- 解答の記録は**使っている端末のブラウザの中だけ**に残ります。サーバーには送られません。
- 機種変更や別の端末で続きから解きたいときは、アプリ内の
  「記録の引き継ぎ・バックアップ」から**引き継ぎコード**を発行してください。
- スマホのホーム画面に追加しておくと、アプリのように開けます。
  - iPhone（Safari）：共有ボタン →「ホーム画面に追加」
  - Android（Chrome）：右上の︙ →「ホーム画面に追加」

### 以前ファイル版（HTML）で解いていた人へ

ファイル版とこのページは、ブラウザから見ると別のものとして扱われます。
そのため**記録は自動では引き継がれません**。
ファイル版を開いて「記録の引き継ぎ・バックアップ」から引き継ぎコードを控え、
このページで同じ画面からコードを入力してください。

## 更新のしかた（管理者向け）

1. このリポジトリのトップページを開く
2. 右上の「Add file」→「Upload files」
3. **`index.html` と `version.json` の2つ**をドラッグして置く
4. 下の「Commit changes」を押す
5. 1〜2分待つと https://terakoyano-syukudai.github.io/ が新しい版になります

> **`version.json` を一緒に上げ忘れないでください。**
> 利用者の端末は、この小さなファイル（約60バイト）だけを見て
> 「新しい版が出たかどうか」を判断しています。
> これが古いままだと、`index.html` を差し替えても誰にも届きません。
> ビルドすると2つとも `site/` に出るので、まとめて上げれば大丈夫です。

利用者側の見え方は次のとおりです。

- アプリを開いたとき、裏で新しい版をダウンロードします（本人には何も出ません）
- **次に開いたときに、黙って新しい版になります**
- 解いている最中に画面が切り替わることはありません
- 更新の確認は最大6時間に1回、約60バイトだけ。新しい版が無ければそれ以上の通信は発生しません

再配布は要りません。**記録は端末に残るので、更新しても消えません。**

## ファイルの説明

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体。これ1つで完結しています |
| `version.json` | 版の番号。**更新のたびに index.html と一緒に上げること** |
| `sw.js` | オフラインで使えるようにする仕組み。触らなくて大丈夫です |
| `manifest.webmanifest` | ホーム画面に追加したときの名前とアイコンの設定 |
| `icon-*.png` / `apple-touch-icon.png` / `favicon-32.png` | アイコン |
| `robots.txt` | クロールの指定。検索よけ本体は `index.html` 内の noindex タグです |
| `.nojekyll` | GitHub 側の余計な変換を止めるための空ファイル。消さないでください |
| `textbook/` | 自作教材（病態薬理 統合教材 全16巻）のビューアと章の画像。下を参照 |

問題データやビルド用のスクリプトは、このリポジトリには置いていません。
手元の `宿題Webアプリ\ソース` フォルダにあります。

## textbook フォルダについて

結果画面の「📖 教材で復習」から開く、自作教材のビューアです。

| もの | 中身 |
|---|---|
| `textbook/index.html` | ビューア本体 |
| `textbook/data.json` | 巻・章・節の一覧（約61KB） |
| `textbook/<巻>/c<章>_<通し>.webp` | 章ごとのスライド画像。376枚・約96MB |

**アプリの更新では触りません。** 画像は教材そのものを直したときだけ上げ直します。
作り直しの手順は手元の `ソース\README.md` の「教材で復習」に書いてあります。

1巻ぶんを上げ直すときは、`Add file → Upload files` のURLの末尾に
`/textbook/<巻>` を付けてからアップロードしてください（例 `.../upload/main/textbook/04`）。
**「Uploading N of M files」の表示が消えてから** Commit changes を押すこと。
途中で押すと、そのぶんが抜けたまま確定します。
